# Culture-MAP V2 멀티유저 사용 가이드

## 개요

이 문서는 Culture-MAP V2의 공개용 멀티유저 사용 가이드입니다. 실제 고객명, 실제 세션 코드, 내부 전용 URL은 포함하지 않습니다.

## 접속

- 로컬 개발: http://localhost:5173
- 배포 환경: 운영자가 제공한 공식 서비스 URL 사용

## 기본 협업 흐름

1. 호스트가 새 세션을 생성합니다.
2. 참가자는 공유된 세션 코드로 입장합니다.
3. 모든 편집 내용은 실시간으로 동기화됩니다.

## 주요 기능

- 세션 기반 협업
- 실시간 노드/연결 편집
- 충돌 방지를 위한 편집 잠금
- 세션 전역 스냅샷 저장/로드

## 운영 권장사항

- 민감정보/개인정보/고객기밀 자료 업로드 금지
- 공유 전 세션 이름과 노드 텍스트의 식별정보 포함 여부 점검
- 공개 데모 환경에서는 테스트용 합성 데이터만 사용

## 문제 해결 체크리스트

- 네트워크 연결 상태 확인
- 브라우저 최신 버전 사용
- 인증/권한 설정 확인
- 브라우저 콘솔 오류 확인
