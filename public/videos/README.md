## 💡 참고사항
1. 영상 생성 후 `public/videos/culture-analyzer-intro.mp4`에 저장
2. 웹 최적화를 위해 H.264 코덱 사용 권장
3. 파일 크기는 2MB 이하로 압축 권장
4. 브라우저 호환성을 위해 .webm 버전도 준비 가능

## 🔧 영상이 없을 경우
- 자동으로 Fallback 애니메이션 표시
- 그라데이션 배경 + "조직문화 분석기" 텍스트
- 부드러운 펄스 효과
